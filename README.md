백엔드 기반의 제품형·도구형 개발자입니다. Java/Spring 계열을 중심축으로 두고,
Spring Boot, MyBatis, JPA, JSP, Maven, Redis, WebSocket, JWT, Nginx, Docker,
AWS Lightsail/EC2, Cafe24 같은 기술을 배포와 운영 맥락에서 다뤄왔습니다.

최근의 중심 관심사는 AI를 활용한 개발 자동화, 하네스 엔지니어링, 에이전트 실행 구조입니다.
`namba-ai`에서는 모델을 바꿔도 유지되는 SPEC 기반 실행 루프, 검증 근거, 리포트, PR 핸드오프를
더 안정적으로 만드는 방향을 실험하고 있습니다.

강점은 문제의 표면보다 구조를 보려는 습관, 운영 환경을 직접 만지는 태도,
문서화와 설계 언어에 대한 관심입니다. 반대로 의식적으로 관리해야 할 부분은
커지는 스코프와 이른 추상화입니다. 그래서 요즘의 기준은 단순합니다:
