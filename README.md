더 안정적으로 만드는 방향을 실험하고 있습니다.

강점은 문제의 표면보다 구조를 보려는 습관, 운영 환경을 직접 만지는 태도,
문서화와 설계 언어에 대한 관심입니다. 반대로 의식적으로 관리해야 할 부분은
